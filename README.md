# Description
Dodge asteroids and earn points
Astrosolid is a 2D pixel-art arcade game where you pilot a spaceship through a dangerous field of asteroids. Dodge incoming obstacles, survive for as long as possible, and push your high score to the limit. With fast-paced gameplay, retro visuals, particle effects, and a minimalist sci-fi atmosphere, Astrosolid combines classic arcade simplicity with challenging survival mechanics.

Every run is a new attempt to survive a little longer.

# Development & Porting
is a faithful port of the original Astrosolid, a pixel-art arcade game developed for PICO-8. The project brings the original experience to C# using Visual Studio and the MonoGame framework, aiming to preserve its core gameplay, mechanics, visual style, and retro identity while moving beyond PICO-8's technical limitations. This new version provides greater control over rendering, performance, and future development, while staying true to the spirit of the original game.
